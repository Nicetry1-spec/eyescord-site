Install

  1. Close Discord completely, including the icon in the system tray.
  2. Open Eyescord-Installer.exe.
  3. Choose Install, then pick the Discord you use: Stable, PTB or Canary.
  4. When it finishes, open Discord. Eyescord has its own section in Settings.

“Windows protected your PC”

The installer isn't code-signed yet, so SmartScreen shows this warning the first time. Click More info, then Run anyway. If you want to be sure the file is the one we published, compare its hash with the one on this page:

Get-FileHash .\Eyescord-Installer.exe

After a Discord update

Discord's updates replace the files Eyescord patches, so Eyescord can vanish after one. Open the installer again and choose Repair.

Uninstall

Open the installer and choose Uninstall. Discord goes back to stock.
